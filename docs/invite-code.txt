PlacePrep invite access is generated by admins inside the app.

Live invite page:
https://placeprep-nine.vercel.app/invite

How to generate a new invite:
1. Sign in with an admin account.
2. Open Settings.
3. Go to invite management.
4. Generate a new invite for admin or user access.

Public signup is disabled.
Do not rely on a static invite code stored in the repository.
